# Changelog

## 1.0.0 — 2026-10-30
- First release for Foundry VTT v13–v14 (verified 14.369) and dnd5e 5.x (verified 5.3.3). GM only.
- One-click SRD import: SRD 5.1 (monsters, spells, items, trade goods, monster features, classes, subclasses, class features, races, backgrounds) and SRD 5.2 (monsters, spells, equipment, feats, origins, classes) copied from the dnd5e system's CC-BY-4.0 compendiums into editable world compendiums.
- Custom import: Foundry/dnd5e JSON exports, simple JSON (Open5e-style field names accepted), CSV, and pasted stat-block text (2014 and 2024 layouts) into dnd5e NPCs, spells and items, with attack / save activities built from the text.
- Licence gate: only CC-BY-4.0, OGL 1.0a and CC0; attribution required for CC-BY and OGL; D&D Beyond / DDB Importer data and non-SRD WotC books refused.
- Duplicate-safe re-imports: unchanged entries skipped, changed ones updated, your local edits kept (configurable: Update / Skip / Overwrite).
- Attribution journal listing every imported source, licence and notice.
